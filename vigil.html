常见问题

Vigil 会持有我的私钥吗？

不会。Vigil 只接受公开地址，只读调用 eth_getBalance / balanceOf / getLogs。它永不签名、永不发送、永不做授权，私钥/助记词/keystore 一律拒绝。

能监控哪些异常？

余额骤降（≥30%）、稳定币骤降、单笔大额转出（≥1 ETH）、交易频率异常飙升。规则可审计，每次运行写 JSON 报告与告警日志。

AI agent 能安全用它吗？

可以。Vigil 把 agent 能接触的范围锁死在你列出的 scope_wallets 里，范围外一律拒绝。agent 得到结构化实时可见性，但永远无法据此行动。

FAQ

Does Vigil hold my private key?

No. It accepts public addresses only and calls eth_getBalance / balanceOf / getLogs read-only. No signing, no sending, no approvals — private keys, seeds and keystores are always refused.

What anomalies can it catch?

Balance drops (≥30%), stablecoin drops, large single outgoing transfers (≥1 ETH), and transaction-velocity spikes. Rules are auditable; every run writes a JSON report and alert log.

Is it safe for an AI agent?

Yes. Vigil locks the agent's reachable scope to the addresses you list in scope_wallets; everything else is rejected. The agent gets structured real-time visibility but can never act on it.

Red line: non-custodial, read-only. Private keys, seeds and keystores never appear in any page, doc, repo or chat.
